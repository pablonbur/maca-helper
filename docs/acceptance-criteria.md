# Acceptance Criteria

## App

- [ ] La app abre localmente en Windows.
- [ ] La app funciona offline.
- [ ] La app carga seed inicial si no hay datos previos.
- [ ] La app persiste cambios.

## Copiado

- [ ] Click en card copia texto al portapapeles.
- [ ] Aparece toast "Copiado".
- [ ] No existe auto-paste.
- [ ] No existe auto-send.
- [ ] No existe automatizacion de apps externas.

## Snippets

- [ ] Se muestran snippets agrupados por categoria.
- [ ] Se pueden buscar snippets.
- [ ] Se puede crear snippet fijo.
- [ ] Se puede editar snippet fijo.
- [ ] Se puede eliminar snippet con confirmacion.
- [ ] Se puede marcar/desmarcar favorito.

## Templates

- [ ] Se puede generar frase desde template.
- [ ] Se puede regenerar otra variante.
- [ ] No quedan placeholders visibles.
- [ ] No quedan dobles espacios.
- [ ] No quedan signos mal espaciados.
- [ ] Se evita repetir exactamente la misma frase inmediata cuando esta activado.

## Import/export

- [ ] Exporta JSON valido.
- [ ] Importa JSON valido.
- [ ] Rechaza JSON invalido con mensaje claro.
- [ ] No borra datos actuales si falla la importacion.

## Tests

- [ ] Hay tests para generacion de templates.
- [ ] Hay tests para normalizacion.
- [ ] Hay tests para slots opcionales.
- [ ] Hay tests para evitar repeticion inmediata.
