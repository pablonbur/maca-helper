# Workflows

## Copiar item fijo

1. La usuaria ve la card "Dato editable".
2. Hace click.
3. La app copia el contenido al portapapeles.
4. Aparece toast "Copiado".
5. La usuaria pega manualmente en el chat.

## Copiar frase variable

1. La usuaria ve la card "Mensaje variable".
2. La app muestra una variante generada.
3. La usuaria puede copiarla con click.
4. Si no le gusta, toca "Otra variante".
5. Copia la nueva variante.

## Editar dato del dia

1. La usuaria toca "Editar" en "Dato editable".
2. Cambia el texto.
3. Guarda.
4. La card queda actualizada.
5. El cambio persiste al cerrar y abrir.

## Crear item fijo

1. La usuaria toca "Nuevo".
2. Elige tipo "Fijo".
3. Carga titulo, categoria y contenido.
4. Guarda.
5. Aparece como nueva card.

## Exportar backup

1. La usuaria toca "Exportar".
2. La app genera archivo JSON.
3. El JSON contiene categorias, snippets, templates, blocks y settings.

## Importar backup

1. La usuaria toca "Importar".
2. Elige JSON.
3. La app valida estructura.
4. Si es valido, reemplaza datos actuales.
5. Si es invalido, muestra error y conserva datos actuales.
